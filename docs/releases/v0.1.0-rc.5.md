# Smart Parking Tower Manager 0.1.0-rc.5

This maintenance release candidate records the verified frontend dependency and toolchain updates now present on `main`.

## Changes since 0.1.0-rc.4

- ESLint updated from 10.11.0 to 10.12.0.
- TypeScript ESLint updated from 8.70.1 to 8.71.2.
- jsdom updated from 27.2.0 to 30.1.2.
- Vitest updated from 5.0.3 to 5.0.5.
- The Vite React plugin updated from 5.1.1 to 5.2.0.
- Vite updated from 7.2.4 to 7.3.7.
- The unsupported React 19.3 update was rejected after frontend and local-runtime failures.

No application API, database schema, business workflow, or deployment boundary changed.

## Verification

Each compatible dependency update passed frontend, security, and complete local-runtime checks before and after merge. The
release commit must pass Backend CI, Frontend CI, Security CI, and Local Runtime CI before the release workflow creates
the tag. Local Runtime CI exercises the integrated business workflow, database recovery, shutdown behaviour, and
bounded occupancy load.

## Deployment boundary

The release is runnable from a fresh clone with `docker compose up --build`. It is not an approval for internet-facing
production use. Complete the external identity-provider, ingress, secret-management, retention, backup, capacity, and
incident-response controls documented in the repository before selecting a production environment.
