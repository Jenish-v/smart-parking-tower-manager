# Smart Parking Tower Manager 0.1.0-rc.1

This is the first integrated release candidate for the maintained local runtime.

## Included workflows

- deterministic allocation and live occupancy across the 7,200-space reference facility
- idempotent entry, exit, lookup, and history
- capacity-safe reservations with atomic arrival fulfillment
- persisted pricing, receipts, adjustments, identity, roles, and audit history
- operator dashboard workflows for parking, reservations, occupancy, and session history
- metrics, structured logs, distributed tracing, backup and restore, and graceful shutdown

## Verification

The release commit must pass Backend CI, Frontend CI, Security CI, and Local Runtime CI before the release workflow
creates the tag. Local Runtime CI exercises the integrated business workflow, database recovery, shutdown behaviour,
and bounded occupancy load.

## Deployment boundary

The release is runnable from a fresh clone with `docker compose up --build`. It is not an approval for internet-facing
production use. Complete the external identity-provider, ingress, secret-management, retention, backup, capacity, and
incident-response controls documented in the repository before selecting a production environment.
