# Smart Parking Tower Manager 0.1.0-rc.4

This maintenance release candidate records the verified frontend dependency and toolchain updates now present on `main`.

## Changes since 0.1.0-rc.3

- React Router DOM updated from 7.18.2 to 7.18.4.
- Vitest updated from 5.0.1 to 5.0.3.
- Testing Library user-event updated from 14.6.1 to 14.6.7.
- Testing Library jest-dom updated from 6.9.1 to 7.0.1 after confirming its Node.js and DOM peer requirements.
- The ESLint globals dataset updated from 16.5.0 to 17.13.0.

No application API, database schema, business workflow, or deployment boundary changed.

## Verification

Each dependency update passed frontend, security, and complete local-runtime checks before and after merge. The release
commit must pass Backend CI, Frontend CI, Security CI, and Local Runtime CI before the release workflow creates the tag.
Local Runtime CI exercises the integrated business workflow, database recovery, shutdown behaviour, and bounded
occupancy load.

## Deployment boundary

The release is runnable from a fresh clone with `docker compose up --build`. It is not an approval for internet-facing
production use. Complete the external identity-provider, ingress, secret-management, retention, backup, capacity, and
incident-response controls documented in the repository before selecting a production environment.
