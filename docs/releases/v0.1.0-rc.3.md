# Smart Parking Tower Manager 0.1.0-rc.3

This maintenance release candidate records the verified frontend test and lint toolchain now present on `main`.

## Changes since 0.1.0-rc.2

- Vitest updated from 4.0.15 to 5.0.1.
- TypeScript ESLint updated from 8.70.0 to 8.70.1.
- React Hooks ESLint plugin updated from 7.0.1 to 7.1.1.
- ESLint updated from 9.39.1 to 10.11.0 after compatibility was available across the maintained plugin set.

No application API, database schema, business workflow, or deployment boundary changed.

## Verification

Each dependency update passed frontend, security, CodeQL, dependency, and complete local-runtime checks before merge.
The release commit must pass Backend CI, Frontend CI, Security CI, and Local Runtime CI before the release workflow
creates the tag. Local Runtime CI exercises the integrated business workflow, database recovery, shutdown behaviour,
and bounded occupancy load.

## Deployment boundary

The release is runnable from a fresh clone with `docker compose up --build`. It is not an approval for internet-facing
production use. Complete the external identity-provider, ingress, secret-management, retention, backup, capacity, and
incident-response controls documented in the repository before selecting a production environment.
